## 设计判断

开屏以下需要重新组织，而不是继续给当前模型增加旋转按钮。上一轮的问题同时出在语义、叙事和视觉：Sailboat／Cruise 被写成支持深度，虚构挑战被拿来做勾选演示，章节套用同一组两栏，Programme 又混用了两种不同的图形风格。类型检查和浏览器操作通过，不能证明这套设计合格。

保留首页与活动页已认可的开屏、原有二维图形、真实合作表单、复制邮箱、多渠道关注入口及静态区域权限说明。本地公开页面已恢复二维展示，实验模型及其源文件留作备选。独立云端测试站尚未更新。

参考 [Apple 香港 iPhone 产品页](https://www.apple.com/hk/iphone-18-pro/) 的叙事方法：每段先提出一个明确重点，视觉围绕这个重点，交互显示有意义的变化。沿用熵序的字体、蓝色氛围及品牌图形，不复制 Apple 的产品造型或品牌外观。

## 先校正议题、项目和挑战的关系

| 内容 | 含义 | 下一版的视觉角色 |
| --- | --- | --- |
| 议题 | 由主办方发起，构成创作方向与整体氛围；对外表述为“几个创作议题”，数量不固定 | 在项目周围形成整体背景和方向说明；避免排成一组任务标签 |
| 项目 | 团队持续构建的同一个作品 | 始终保持一个完整主体，选多个方向也不拆成多个方块 |
| 挑战 | 合作方带来的具体问题，预期数十项；自愿参与 | 每项以问题、资源、参与说明呈现，单独列在项目关联的具体任务区 |
| Sailboat／Cruise | 挑战适应不同需求的两种参与形态 | 同等字号、同等面积、同等可见性；按需求与参与过程解释 |
| Challenge Station | 各项挑战的技术交流驻点 | 接在挑战参与过程之后，明确可以问什么、获取什么支持 |
| Programme | 主办方策划的现场内容，包含受邀讲者的分享、工作坊等 | 独立讲述选手如何参加、如何带回项目，与挑战招募分开 |
| Tent／Custom Activation | 标准展示空间与定制体验 | 只在合作邀请中呈现，不放入选手创作层级 |

删除“挑战示例 01–04”和第二个虚构议题。尚未公布的内容，用真实筹备状态说明，不用空白占位卡撑出数量。开放创作只保留自然中文的小节，不单独显示 Nobody Asked 或“没人在问”。

真实议题和挑战发布后，官网先提供浏览与说明；项目绑定仍由 Passport 承接。项目可以关联任意数量的议题和挑战。若展示“两项议题、三项挑战”的解释图，主题方向作用于一个完整项目的背景；三个挑战在旁边显示为具体问题列表，各自有内容层级。官网不制作与实际项目资料脱节的伪编辑器。

## 全页分镜

| 段落 | 读者要弄清什么 | 版式和视觉 | 交互与衔接 |
| --- | --- | --- | --- |
| 开屏 | 名称、香港、五日、免费参赛 | 保留认可的开屏及两行宣传语 | 保留克制品牌动效；章节导航进入正常阅读 |
| 五日体验 | 从相遇到构建再到展示，构建与公众参与贯穿五日 | 宽幅 Day 1／Day 2–4／Day 5 时间轴；中间段更宽，配已认可的二维构建图形 | 滚动时进度标记沿时间轴推进，三个时段正文一直可读；第五天保留拟定 12:00 提交 |
| 城市探索 | 可以正常离场，城市观察可以带回项目 | 作为五日体验的短支线，文字与时间轴共享左侧基线；有相关、获准素材时再使用图片 | 不另起意义不明的夜景横幅，不重复街道照片 |
| 议题与项目 | 几个创作方向；一件作品可回应多个方向 | 章标题大字“议题”，小字“由主办方发起”；宽幅整体构图展示方向围绕同一项目；开放创作是简短补充 | 从整体氛围过渡到项目主体，避免点击假的议题选项；筹备状态直接可见，不显示数量区间 |
| 挑战 | 数十项具体问题，与议题是不同层次；可以参与多项 | 沿用上段的项目主体，旁边展开具体问题的结构说明；大字“挑战”，小字“由合作方带来” | 项目在过渡中保持完整，挑战以问题清单接入；未发布时不模拟题目与合作方 |
| Sailboat／Cruise | 两种需求如何参与 | 一组同等重要、直接展开的对照内容，各自显示任务特点、选手行动、资源及交流过程 | 重要区别不放进折叠；细节才可展开；不采用价格套餐或高低等级样式 |
| Programme | 可以学什么、交流什么、如何邀请别人体验 | 同一套二维图形语言；工作坊占主要视觉，分享、导师交流、作品体验形成有主次的排版 | 若使用切换，必须同时改变相关场景、内容和参与过程；正文仍有静态完整阅读路径，不重复电脑模型 |
| 生活支持 | 怎么休息、怎么吃饭、怎么申请往返交通 | 三个清晰连续的内容段，共享图文基线；住宿沿用双床图及 12 小时时段，膳食一幅图整合三餐和热食，交通显示通常居住地与会场的往返 | 住宿时间标记从锁定到 +12h；交通按申报、获批、预支、凭证核销显示顺序；关键条件不藏进标签页 |
| 参加方式 | 选手与游客的不同入口和使用区域 | 两条真实身份路径；公开区域／构建区／休息区规则同时可见 | 关注入口打开渠道菜单；已有链接可使用，未接通渠道显示真实状态 |
| FAQ | 补充操作、费用及例外 | 左侧简短标题，右侧折叠问题列表 | 默认折叠，不承担首次解释重要制度的责任 |
| 合作邀请 | 怎样联系、可以怎样参与 | 简短四方向：挑战、现场内容、展示体验、生活与资源支持；选择后打开现有真实表单 | 表单＋Turnstile＋真实发送反馈；邮箱复制；不与创作章节混成套餐 |
| 页底 | 谁发起、怎样加入 | 组织信息、About、加入入口及法定页脚 | 保留旧链接、Cookie 设置、语言与主题功能 |

议题和挑战保留独立锚点及导航，但视觉上形成连续叙事。“五日体验 → 创作关系 → 现场交流 → 生活支持 → 参加”是主要阅读线；FAQ 和合作邀请随后收束。

## Sailboat／Cruise 的选手视角文案草案

以下是下一次实施拟新增或改写的实质文案，不是当前已发布正文；三语言应在中文语义确认后一起调整。后来确认的“两种需求取向”覆盖旧版“更深入支持”的层级表达。

**两种挑战参与方式**

合作方将带来不同的具体问题。Sailboat 与 Cruise 对应不同的任务特点与参与过程。每项挑战的工具、资源、提交要求和交流安排，会在题目发布时说明。

**Sailboat｜围绕明确的问题展开尝试**

从清楚的任务说明开始，了解可用的工具和资源。你和队友可以在构建时到挑战驻点请教工程师，再提交成果，参与展示与评议。

过程：阅读任务与资源 → 构建与技术交流 → 提交、展示与评议。

**Cruise｜在技术与场景的结合中探索**

围绕需要结合技术、设备或现场场景的问题展开创作。主办方与合作方共同设计任务和参与过程，你和队友按具体安排构建、进行体验测试，并通过交流与评议获得反馈。

过程：了解任务与参与安排 → 构建与体验测试 → 展示、评议与反馈。

视觉上不使用级别、奖章、豪华底色、面积差异来区分这两种形态。合作方适用需求的说明放在合作邀请或独立资料中，不占用这组面向选手的介绍。

## 对齐、字级与留白的规则

- 最大内容宽度 1240px；桌面 12 栏、24px 栏间距；外侧留白随屏幕变化，常用桌面为 48px，手机为 20px。长正文单独限制行长。
- 全页使用三种有明确职责的构图：居中的章节开场；左侧说明／右侧视觉的 4＋8 栏解释；对齐同一基线的事实与规则列表。时间轴及创作关系图可以跨满 12 栏。
- 居中用于进入新章节，说明与规则左对齐；不会为了“变化”任意交换左右位置。Sailboat／Cruise 使用对称的 6＋6 栏，两者权重一致。
- 章节标题初始目标为桌面 48–72px、手机 32–40px；正文桌面 18px、手机 16px；关键规则不降成小注脚。英文独立校验行长。
- 大章节间距初始目标为桌面 112–144px、手机 64–80px；同一章节内部 24／40／64px。用标题与视觉共同建立段落边界，不通过无内容的大块色底撑满屏幕。
- 深浅主题分别调整背景、图形对比和阴影。二维线条、图形比例与材质表达保持一致；不混用不同完成度的 2D 与 3D。

## 动效要解释的变化

| 位置 | 动效的解释任务 | 限制 |
| --- | --- | --- |
| 五日时间轴 | 相遇、构建、展示发生在同一段五日经历中 | 时间轴文字初始可见；不把五天拆成五次整屏翻页 |
| 议题 → 项目 → 挑战 | 方向形成整体语境，具体问题关联到完整作品 | 桌面最多约 1.5 个视口的短驻留场景；页面仍自然滚动，导航可以直接跳过 |
| 住宿 | 房间锁定后从 0h 到 12h 的使用时段 | 两人共享及轮换文字始终显示；不模拟真实房间库存或预订 |
| 其余章节切换 | 标明进入新主题，帮助理解版式关系 | 约 240–400ms 的短过渡，位移约 8–12px；不让每段文字逐字飞入 |

优先做三处有解释价值的运动，不把所有章节都变成动画展示。只旋转模型而没有信息变化的交互先取消。手机使用自然纵向阅读，不做长时间固定场景。减少动态效果时直接展示全部最终内容；加载、动画失败或跳转到锚点时正文不能被隐藏。

- 不虚构现场、设备、酒店、合作方、讲者和参赛作品，不重复同一素材冒充不同内容。

## 验收标准

- 不点开任何下拉说明，也能知道是几个议题与多项具体挑战，Sailboat／Cruise 是参与形态。公开页面不使用固定数量或区间凑占位内容。
- 两个议题与三个挑战关联到一件作品时，作品仍然是一个主体，方向与具体问题视觉分层。
- 不出现虚构挑战编号、同款电脑重复使用、只旋转却没有解释价值的交互。
- 每个主要视觉对应一个可说清的内容目的；Programme 的图形风格一致。
- 住宿双人共享、锁定起 12 小时轮换；免费膳食；按通常居住地、获批路线及额度申请交通补贴，包括香港本地交通。这些条件直接可读。
- 游客免费登记、夜间可进入开放区域；选手邀请游客进入构建区；选手休息区专用；正常离场不算退出。身份规则同时展示。
- 桌面、手机、深浅主题和三语言检查无溢出；导航、锚点、FAQ、关注菜单及真实表单可操作；键盘与减少动态效果模式能读完整内容。
- 运行实际类型检查、构建与相关接口测试。测试通过与设计获得认可分别记录，不互相替代。
